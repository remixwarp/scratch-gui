1. 什么是自定义插件

自定义插件是一个单个 JavaScript 文件（ES Module 格式），导出： manifest（插件的清单/元数据）和 export default（入口函数）。 导入后它会在编辑器里运行，拥有对编辑器和当前作品的完全访问权限——因此请只导入你信任的代码。

导入方式（插件设置 → 自定义插件）：从文件导入...、从网址加载... 或 粘贴源代码...。导入后需在列表中启用。本页所有示例都可以直接复制、粘贴到「粘贴源代码...」中导入。

2. 插件文件格式

一个插件文件包含两个关键导出。结构必须固定，否则导入会失败并提示格式错误。

export const manifest = {
    name: '我的插件',            // 必填：插件名称
    description: '插件说明',      // 可选：显示在列表中的描述
    tags: ['custom'],           // 可选：标签（会自动补 'custom'）
    settings: [],               // 可选：插件设置项（见下文）
    css: '',                    // 可选：插件自带样式
    enabledByDefault: false     // 可选：默认是否启用
};

export default async function ({addon, console, msg}) {
    // 在这里写你的插件逻辑
    // 入口函数在插件被启用时运行一次
    console.log('插件已启动');
}

3. manifest 清单参考

字段类型必填说明
namestring是插件名称，显示在列表里。
descriptionstring否插件描述。
tagsstring[]否标签。会自动补上 'custom'。
settingsobject[]否设置项数组，会在插件卡片中渲染出控件（见 下一节）。
cssstring否插件自带的 CSS 文本。提供后会自动作为 userstyle 注入。
enabledByDefaultboolean否是否默认启用（导入后默认不启用）。

4. 设置项类型（settings）

在 manifest.settings 里定义，每个设置项会生成一个控件。支持的 type 如下：

type说明相关字段
boolean开关default
integer整数输入default、min、max
positive_integer非负整数default、max
string文本输入default
untranslated文本输入（不过翻译）default
color颜色选择器default（十六进制）
select下拉选择default、options

所有设置项都需要一个唯一的 id。可以用 name 作为显示标题。select 的 options 是 {name, value} 数组。

export const manifest = {
    name: '带设置的插件',
    settings: [
        { id: 'enabled', type: 'boolean', name: '启用', default: true },
        { id: 'speed', type: 'positive_integer', name: '速度', min: 0, max: 100, default: 10 },
        { id: 'color', type: 'color', name: '主色', default: '#75c1c4' },
        { id: 'mode', type: 'select', name: '模式', default: 'a', options: [
            { name: '模式 A', value: 'a' },
            { name: '模式 B', value: 'b' }
        ]}
    ]
};

export default async function ({addon}) {
    // 读取设置值
    console.log('enabled =', addon.settings.get('enabled'));
    console.log('speed =', addon.settings.get('speed'));
    console.log('color =', addon.settings.get('color'));
    console.log('mode =', addon.settings.get('mode'));

    // 设置变化时响应
    addon.settings.addEventListener('change', () => {
        console.log('设置已更新:', addon.settings.get('speed'));
    });
}

5. 入口函数与 addon 参数

入口函数在插件启用时被调用，并接收到一个参数对象。以下是可用参数：

参数说明
addon核心对象，包含 tab、settings、self 三大部分（见下节 API 参考）。
console控制台对象，用于日志调试（console.log/error 等）。
global全局对象（相当于 window）。
msg翻译函数 msg(key, vars)。注意：自定义插件没有附带翻译文件，因此它通常原样返回 key，主要用于内置插件。
safeMsg与 msg 相同，但会对文本做 HTML 转义。
「不保证可用」提醒：自定义插件没有翻译资源，因此 msg / safeMsg 一般派不上用场，建议直接在插件里使用中文文本。

6. API 完整参考

下面的 API 全部来自代码库中真实可用的实现（src/addons/api.js 与 src/addons/custom-plugins.js）。未提供、或对自定义插件无意义的项已省略。

6.1 addon.tab — 与编辑器界面交互

API说明
addon.tab.traps.vmScratch 虚拟机实例，可访问项目目标、积木、运行时等。
await addon.tab.traps.getBlockly()获取 Blockly（ScratchBlocks），用于修改积木外观、右键菜单等。
addon.tab.traps.getWorkspace()获取当前 Blockly 工作区。
await addon.tab.traps.getPaper()获取画板编辑器（造型编辑）的 Paper 作用域，需先进入画板标签页。
addon.tab.reduxRedux store。.state 读取状态；addEventListener('statechanged', fn) 监听初始化和状态变化。
await addon.tab.waitForElement(selector, opts)等待某个 DOM 元素出现并返回它。非常适合注入 UI。opts 见下。
addon.tab.appendToSharedSpace({space, element, order, scope})把元素插入到编辑器的已知位置（舞台头部、绿旗旁、声音标签后等）。
addon.tab.addBlock(proc, {args, displayName, callback})添加一个点击执行的自定义积木。proc 与 args 中的参数数量必须一致；回调为 (args, thread)。
addon.tab.getCustomBlock(proc)获取由 addBlock 创建的自定义积木描述。
addon.tab.createBlockContextMenu(cb, opts)向积木右键菜单注入项目。opts: workspace/blocks/flyout/comments 布尔值。
addon.tab.createEditorContextMenu(cb, opts)向编辑器右键菜单（舞台/角色列表等）注入项目。
await addon.tab.copyImage(dataURL)把图片 dataURL 复制到剪贴板。
addon.tab.scratchMessage(id)按 id 获取编辑器自身的界面文案。
addon.tab.scratchClass(...names)按类名前缀取到当前的 CSS 类名（Scratch 类名会带哈希后缀）。
addon.tab.editorMode当前模式：editor / fullscreen / projectpage / embed。
addon.tab.displayNoneWhileDisabled(el, opts)让元素在插件被禁用时自动隐藏。
addon.tab.direction界面方向：ltr 或 rtl。
addon.tab.createModal(title, opts)在编辑器中创建可复用的弹窗。返回弹窗对象。
addon.tab.confirm(...)弹出确认框。
addon.tab.prompt(...)弹出输入框。
addon.tab.recolorable()创建一个跟随主题主色重着色的图片元素。

waitForElement 的 opts 支持：

  • markAsSeen — 只返回第一个匹配并记住它（循环调用时不重复）。
  • condition — 函数，返回 true 才匹配。
  • reduxCondition — 基于当前 Redux state 的条件函数。
  • reduxEvents — 监听这些 Redux 动作后才开始匹配。

appendToSharedSpace 的 space 支持以下取值：

  • stageHeader — 非全屏舞台头部。
  • fullscreenStageHeader — 全屏舞台头部。
  • afterGreenFlag — 绿旗按钮之后。
  • afterStopButton — 停止按钮之后。
  • afterSoundTab — 声音标签之后。
  • monitor — 变量监视器右键菜单。
  • assetContextMenuAfterExport / assetContextMenuAfterDelete — 资源右键菜单。
  • paintEditorZoomControls — 画板缩放控件。

6.2 addon.settings — 读取插件设置

API说明
addon.settings.get(id)读取某个设置项当前值。
addon.settings.addEventListener('change', fn)设置发生变化时触发。

6.3 addon.self — 插件自身状态

API说明
addon.self.id插件唯一 id。
addon.self.disabled插件是否被禁用（布尔）。
addon.self.addEventListener('disabled', fn)插件被禁用时触发，可清理资源。
addon.self.addEventListener('reenabled', fn)插件被重新启用时触发。
addon.self.getResource(path)加载插件内嵌资源（种子文件）。

7. 完整示例插件

以下是可直接复制导入的真实示例，复制后粘贴到「粘贴源代码...」即可导入启用。可直接运行

示例 1：在舞台头部加一个按钮

向编辑器的舞台头部插入一个按钮，点击后改变按钮自身颜色并打印日志。

export const manifest = {
    name: '按钮示例',
    description: '在舞台头部添加一个按钮',
    settings: [
        { id: 'color', type: 'color', name: '按钮颜色', default: '#75c1c4' }
    ]
};

export default async function ({addon, console}) {
    // 创建一个按钮
    const button = document.createElement('button');
    button.textContent = '自定义按钮';
    button.style.cssText = 'margin:0 4px;border:none;border-radius:4px;' +
        'padding:4px 10px;background:#75c1c4;cursor:pointer;';

    // 插入到舞台头部（绿旗按钮之后）
    addon.tab.appendToSharedSpace({
        space: 'afterGreenFlag',
        element: button,
        order: 99
    });

    // 点击后更换按钮颜色，并读取插件设置
    button.addEventListener('click', () => {
        const color = addon.settings.get('color');
        button.style.background = color;
        console.log('按钮被点击，颜色设置为', color);
    });
}

示例 2：添加一个自定义积木

向积木区添加一个新的「自定义积木」，点击/运行时执行回调。回调参数为 (args, thread)，可通过 thread.target 获取当前目标。

export const manifest = {
    name: '自定义积木示例',
    description: '添加一个自定义积木，运行后在控制台打印信息'
};

export default async function ({addon, console}) {
    addon.tab.addBlock('自定义积木 %s 份', {
        args: ['数量'],
        displayName: '自定义积木 %s 份',
        callback: (args, thread) => {
            const count = args['数量'];
            const target = thread && thread.target;
            console.log('自定义积木运行', count, '次');
            console.log('当前目标：', target ? target.getName() : '未知');
        }
    });
}

示例 3：给积木右键菜单注入项目

使用 Blockly API 往积木的右键菜单里加一个「控制台输出」项目。右键菜单回调为 (items, block)，右键空白工作区时 block 可能为 undefined，需要判空。

export const manifest = {
    name: '积木右键菜单示例',
    description: '给积木右键菜单添加一个「控制台输出」项目'
};

export default async function ({addon, console}) {
    // 先拿到 Blockly（异步）
    await addon.tab.traps.getBlockly();

    addon.tab.createBlockContextMenu((items, block) => {
        if (!block) {
            return items; // 右键的是空白区域，不注入
        }
        items.push({
            text: '控制台输出这个积木',
            enabled: true,
            callback: () => {
                console.log('积木类型:', block.type);
                const pos = block.getRelativeToSurfaceXY();
                console.log('积木位置:', pos.x, pos.y);
            }
        });
        return items;
    }, {blocks: true});
}

示例 4：使用 settings + 纯 JS 注入样式

export const manifest = {
    name: '样式注入示例',
    description: '按设置给舞台区域加边框',
    settings: [
        { id: 'width', type: 'positive_integer', name: '边框宽度', default: 3 }
    ]
};

export default async function ({addon}) {
    const style = document.createElement('style');
    document.head.appendChild(style);

    const apply = () => {
        const w = addon.settings.get('width');
        style.textContent = '.stage_stage_ {\n  outline: ' + w + 'px solid #75c1c4;\n}';
    };
    apply();
    addon.settings.addEventListener('change', apply);
}

8. 纯 CSS 插件

如果你只想改样式，甚至不需要写 JavaScript 逻辑——直接在 manifest.css 里写 CSS 即可，运行时会被自动注入。

export const manifest = {
    name: '圆角化 UI',
    description: '把按钮和菜单改成圆角',
    css: [
        '[class*="button_button"],',
        '[class*="menu-bar_menu-bar-item_"] {',
        '    border-radius: 12px;',
        '}'
    ].join('\n')
};

export default async function () {
    console.log('纯 CSS 插件已加载');
}
提示：Scratch 的类名带哈希后缀（如 button_xyz_），在 CSS 里建议用 [class^="button_"] 或 [class*="menu-bar_menu-bar-item_"] 这类前缀/部分匹配。

9. 注意事项与常见问题

  • 格式严格：入口函数必须写成 export default async function ({addon}) {...} 的形式；manifest 必须是 export const manifest = {...}。无法解析时会提示「插件文件格式无效」。
  • 信任安全：插件拥有完全访问权限，会执行任意代码。只在可信来源导入。
  • 本地存储：插件代码保存在浏览器的 localStorage 中，清除浏览器数据会丢失已导入的插件。
  • 启用后生效：导入插件后需要切换开关启用它，入口函数才会运行。
  • 清理：在 addon.self.addEventListener('disabled') 里移除你动态创建的元素、监听器和 interval，避免禁用后残留。
  • CSS 选择器：Scratch 的 CSS 类名带哈希，优先用属性前缀匹配，或用 addon.tab.scratchClass 在 JS 里取类名。
export const manifest = {
    name: '资源清理示例',
    description: '演示在插件被禁用时清理动态 UI 与定时器'
};

export default async function ({addon, console}) {
    const div = document.createElement('div');
    div.textContent = '我是一些临时 UI';
    document.body.appendChild(div);

    const timer = setInterval(() => {
        console.log('插件心跳');
    }, 1000);

    // 禁用时清理
    addon.self.addEventListener('disabled', () => {
        div.remove();
        clearInterval(timer);
        console.log('已清理资源');
    });
}
